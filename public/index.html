Behind this portfolio prototype

LoveTalks explores a simple product flow: a short questionnaire, three conversation starters, and a deeper look at one idea.

It demonstrates a frontend-to-backend API integration, with local sample responses by default and optional model-generated text. It is not a trained recommendation model or a statistical matching system.

Fixed choices only · No browser storage · No analytics
